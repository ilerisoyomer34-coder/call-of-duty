## Komutlar (web)
- `cd web && npm install`
- `npm run build` üç çıktı üretir:
  - `dist/index.html`: çevrimdışı, three gömülü.
  - `dist/artifact.html`: three CDN'den.
  - `dist/pwa/`: yüklenebilir uygulama. İçinde three paketli, modeller gerçek dosya; `manifest.webmanifest`, `icons/` ve `sw.js` var. Gizlilik politikası `privacy.html` (kaynak `src/pwa/privacy.html`, önbelleğe girmez).
  - `dist/app/`: mağaza uygulaması (depoya girmez). PWA gibi ama manifest/hizmet çalışanı yok, yazı tipleri yerel (`src/fonts/`, `window.__DS_FONTS`; Google'a ön bağlantı bile yok), `__STORE__` açık.
- Yayın (GitHub Pages): `npm run deploy:pages` commit'lenmiş `dist/pwa/`'yı `gh-pages` dalına gönderir. Aynı iş push'ta `.github/workflows/pages.yml` ile kendiliğinden de yapılır.
- Mağaza (ayrıntı `Docs/STORE_RELEASE.md`):
  - `cd mobile && npm install && npm run sync` (web'i derler, `cap sync`); `npm run android` / `npm run ios` IDE'yi açar; `npm run assets` simge ve açılış görsellerini `web/src/pwa/icon.svg`'den şablondaki her PNG'nin boyutunda yeniden çizer (iOS'ta saydamlık kanalsız). `mobile/README.md` şablonun üstüne elle yapılan ayarları listeler (yatay, tam ekran, ekran kararmaz, GLES3, Info.plist gerekçeleri).
  - `cd web && node tools/store-assets.mjs [play|iphone|ipad|art]` → `store/` (Play 1920×1080, iPhone 6,9" 2868×1320, iPad 13" 2752×2064; üstte Türkçe başlık şeridi + küçültülmüş oyun görüntüsü; Play simgesi ve 1024×500 tanıtım görseli). Yazılımsal GPU'da bir set ~6 dk; tıklamalar sayfa içinden (`el.click()`), Playwright tıklaması yüksek kalitede zaman aşımına düşer. Metinler `store/LISTING.md`.
  - Yazı tipleri: `node tools/fetch-fonts.mjs` (Google Fonts → `src/fonts/` Latin + Latin-ext, OFL metinleri; çıktı commit'lenir).
  - Şikâyetler: `node server/moderate.mjs` (liste), `node server/moderate.mjs sil <oyuncu kimliği>`.
  - Yayın ön denetimi: `cd web && npm run audit:release` (`tools/release-audit.mjs [--built]`: API 36, Capacitor güvenlik bayrakları, `allowBackup="false"`, gizlilik/mağaza metni, imza anahtarı depoda yok, girdi/kayıt düzeltmeleri yerinde). Her push'ta `.github/workflows/quality-gates.yml` (npm ci → birim testleri → derleme → ön denetim; yayın yapmaz, duman koşmaz). Yayın kapıları ve elle yapılacaklar `Docs/RELEASE_QA_TR.md` (kaynağı kullanıcının yüklediği v1.2 kalite paketi).
  - Gizli bilgi taraması: `cd web && node tools/secret-scan.mjs [--history]` (izlenen dosyalarda anahtar/belirteç/özel anahtar, izlenmemesi gereken dosya adları; bulunan değeri yazmaz). Kalite kapısında npm ci'den önce; ardından `npm audit --omit=dev --audit-level=high`.
- Yapay zekâlı telsiz (sunucu yolu): `ANTHROPIC_API_KEY` sunucunun ortamında (ev sunucusunda `web/server/host.env`, başlatıcı `aiEnv` ile geçirir); isteğe bağlı `AI_MODEL` (varsayılan `claude-opus-5-5`), `AI_EFFORT` (low), `AI_RADIO=0|1`. Anahtar kullanıcıdan sohbette istenmez; kullanıcı dosyaya kendisi yazar. Paket `@anthropic-ai/sdk` (sabit sürüm, `dependencies`); yüklü değilse sunucu açılır, yalnız yapay zekâ kapalı (başlatıcılar eksikse `npm install` yapar).

## Kurallar
- Kod içi isimler İngilizce, yorumlar Türkçe ve "neden"i anlatır.
- Ayar değerleri `config.js`'de; kodda sihirli sayı bırakma. Kataloglar (zırh, mağaza, görevler, canlandırma, tim, komut sözlüğü, telsiz replikleri, silahların görünen bilgileri) `web/src/data/*.json`'da; `import X from './data/x.json' with { type: 'json' }` ile alınır (esbuild ve Node testleri aynı sözdizimini okur). Denge değişikliği kod değil veri değişikliğidir.
- Operasyon Güncellemesi (Modül A–E, belge sohbette; plan: F1–F10). Ortak altyapı:
  - Olaylar `src/events.js` → `EV` sabitleri; `game.events` ile yayımlanır. Eski olaylar (`enemyKilled`, `allyDown`…) adlarıyla sürer.
  - Kayıt `src/save.js` → tek anahtar `demirsafak.save` (`version`). Eski `demirsafak.{settings,progress,loadout}.v1` ilk açılışta içe aktarılır, silinmez. Ayarlar `save.data.settings`; ilerleme `save.data.progress` (oyun nesnenin kendisini değiştirip `save.update(null, { now: true })` çağırır). Yazma 250 ms toplanır; satın alma ve ilerleme `now: true`.
  - Çevrim dışı yedek `src/saveBackup.js`: her `flush`'ta ana kayıttan sonra `demirsafak.save.offlineBackup.v1` (izin listesi `BACKUP_FIELDS`/`BACKUP_SETTINGS`: profil, hesap belirteci, `serverUrl` yok).
